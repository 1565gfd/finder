# FINDER

Быстрый поиск файлов по имени для Windows. Показывает, **где** лежит файл на диске, **не открывая** его — сравниваются только имена через файловую систему.

  <img src="finder.png" width="120" alt="FINDER icon">
</p>

## Возможности

- 🔎 Поиск по части имени, по маске (`*.pdf`), точному имени или расширению
- ⚡ **Многопоточный движок** + быстрый Win32-API `FindFirstFileEx` (режим LargeFetch) — обход в несколько раз быстрее обычного `Directory.GetFiles`
- 🛑 Кнопка **СТОП** — поиск можно прервать в любой момент
- 🪟 Оконный интерфейс (WPF): тёмная тема, своя строка заголовка, плавные анимации, экран загрузки
- 📁 Двойной клик по результату открывает **папку** с файлом (сам файл не запускается)
- 🚫 Пропуск ссылок-junction/symlink — без зацикливания на системных папках

## Запуск

Скачайте и запустите **`FinderApp.exe`** (Windows 10/11, .NET Framework 4.x уже встроен в систему — устанавливать ничего не нужно).

Рядом с `.exe` должны лежать `finder.ico` и `finder.png` — для иконки окна и заставки.

## Сборка из исходника

Компилятор `csc.exe` входит в состав Windows (.NET Framework). Просто запустите:

```bat
build.bat
```

Или вручную:

```bat
%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /optimize+ /target:winexe /win32icon:finder.ico /out:FinderApp.exe FinderApp.cs
```

## Linux (SteamOS / Arch / любой)

Для Linux есть отдельная версия — скрипт **`finder.sh`** (без установки зависимостей, использует стандартный `find`). `.exe` на Linux не запускается — это Windows-программа.

```bash
chmod +x finder.sh          # один раз — сделать исполняемым
./finder.sh steam ~/        # искать "steam" в домашней папке
./finder.sh "*.log" /var/log
./finder.sh -e pdf ~/Documents
./finder.sh -all steam      # по всей системе
./finder.sh                 # интерактивно
```

Файлы при поиске **не открываются** — читаются только имена.

## Технологии

- **C# / WPF** — интерфейс, анимации, экран загрузки
- **Win32 `FindFirstFileEx`** (P/Invoke) — быстрое перечисление каталогов
- **Многопоточность** — обход папок распараллелен по числу ядер
