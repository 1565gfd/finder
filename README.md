# FINDER

Быстрый поиск файлов по имени для Windows. Показывает, **где** лежит файл на диске, **не открывая** его — сравниваются только имена через файловую систему.

## ⬇️ Скачать

**Windows** — [**FinderApp.exe**](https://github.com/1565gfd/finder/releases/latest/download/FinderApp.exe) · один файл, скачал и запустил (иконка встроена).

**Linux (SteamOS / Arch / любой):**
- окно/GUI — [**finder_gui.py**](https://github.com/1565gfd/finder/releases/latest/download/finder_gui.py) → `python3 finder_gui.py`
- терминал — [**finder.sh**](https://github.com/1565gfd/finder/releases/latest/download/finder.sh) → `chmod +x finder.sh && ./finder.sh`

Все версии и обновления — на [**странице релизов**](https://github.com/1565gfd/finder/releases/latest).

> `.exe` — только для Windows; на Linux запускай `finder_gui.py` или `finder.sh`.

## ⚠️ Windows может ругнуться при запуске — это нормально

При первом запуске `FinderApp.exe` Windows может показать синее окно **«Система Windows защитила ваш компьютер / SmartScreen»**, а антивирус — пометить файл. **Это не вирус.**

Причина: программа **не подписана** платным сертификатом и **новая** (нулевая репутация). Такое окно выскакивает на любую свежую неподписанную программу. Исходный код открыт — можно проверить или собрать самому (`build.bat`).

**Как запустить:**
1. В окне SmartScreen нажми **«Подробнее»**.
2. Нажми появившуюся кнопку **«Выполнить в любом случае»**.

Чтобы больше не спрашивало: правый клик по файлу → **Свойства** → галочка **«Разблокировать»** → **ОК**.

Если какой-то антивирус даёт срабатывание — это **ложное** (эвристика/ML на неподписанный .exe). Можно добавить файл в исключения или собрать из исходника. На **Linux** этого нет — там `finder_gui.py` / `finder.sh`.

## Возможности

- 🔎 Поиск по части имени, по маске (`*.pdf`), точному имени или расширению
- ⚡ **Многопоточный движок** + быстрый Win32-API `FindFirstFileEx` (режим LargeFetch) — обход в несколько раз быстрее обычного `Directory.GetFiles`
- 🛑 Кнопка **СТОП** — поиск можно прервать в любой момент
- 🪟 Оконный интерфейс (WPF): тёмная тема, своя строка заголовка, плавные анимации, экран загрузки
- 📁 Двойной клик по результату открывает **папку** с файлом (сам файл не запускается)
- 🚫 Пропуск ссылок-junction/symlink — без зацикливания на системных папках
- 💾 **Экспорт результатов** в TXT / CSV / JSON / HTML (с запросом, режимом, где искал, кол-вом и временем)
- ⚙ **Настройки**: учитывать регистр, пропускать скрытые файлы, лимит результатов

## Запуск

Скачайте и запустите **`FinderApp.exe`** (Windows 10/11, .NET Framework 4.x уже встроен в систему — устанавливать ничего не нужно).

Рядом с `.exe` должны лежать `finder.ico` и `finder.png` — для иконки окна и заставки.

## Сборка из исходника

Компилятор `csc.exe` входит в состав Windows (.NET Framework). Просто запустите:

```bat
build.bat
```

Или вручную:

```bat
%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /optimize+ /target:winexe /win32icon:finder.ico /out:FinderApp.exe FinderApp.cs
```

## Linux (SteamOS / Arch / любой)

Для Linux есть отдельная версия — скрипт **`finder.sh`** (без установки зависимостей, использует стандартный `find`). `.exe` на Linux не запускается — это Windows-программа.

```bash
chmod +x finder.sh          # один раз — сделать исполняемым
./finder.sh steam ~/        # искать "steam" в домашней папке
./finder.sh "*.log" /var/log
./finder.sh -e pdf ~/Documents
./finder.sh -all steam      # по всей системе
./finder.sh                 # интерактивно
```

Файлы при поиске **не открываются** — читаются только имена.

### Графическая версия для Linux

Если хочется окно, а не терминал — есть **`finder_gui.py`**: запускает локальный сервер и открывает интерфейс FINDER (тёмная тема) в браузере. Нужен только `python3` (он предустановлен на SteamOS/Arch), ничего ставить не надо.

```bash
python3 finder_gui.py
```

Откроется страница с поиском. Двойной клик по результату открывает папку с файлом. Закрыть — `Ctrl+C` в терминале.

## Технологии

- **C# / WPF** — интерфейс, анимации, экран загрузки
- **Win32 `FindFirstFileEx`** (P/Invoke) — быстрое перечисление каталогов
- **Многопоточность** — обход папок распараллелен по числу ядер
